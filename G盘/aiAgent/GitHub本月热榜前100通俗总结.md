## 一句话看懂本月风向

本月 GitHub 最热闹的，几乎都围着 **AI 干活**：AI Agent / 智能体、前端 / Web / UI、视频 / 多媒体 / 会议。
榜首前五是 **OmniRoute**、**graphify**、**orca**、**OpenCut**、**skills**，榜首单月新增约 27,829 Star——大家在找「能替人干活的 AI 工具」，而不只是看模型本身。
